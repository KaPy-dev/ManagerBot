# ManagerBot

Telegram-бот для сбора заявок (бриф) с пересылкой в чат менеджеров.

## Быстрый старт

```bash
pip install -r requirements.txt
python main.py
```

или через Docker:

```bash
docker compose up -d --build
```

## Смена бота (передача заказчику)

1. Создать бота у @BotFather, получить токен.
2. В `configuration/conf.env` заменить:
   - `TOKEN` — токен нового бота;
   - `OWNER_ID` — Telegram ID владельца (узнать через @userinfobot).
3. Юзернейм бота нигде в коде не используется — менять ничего не нужно.
4. У @BotFather боту можно включить `/setjoingroups` → Enable, чтобы его можно было добавлять в группы.
5. Добавить бота в группу/канал менеджеров и назначить администратором
   (иначе он не видит сообщения группы и не сможет писать в канал).
6. Владелец в боте: `/admin` → «📌 Чат для заявок» → выбрать группу из списка.
   ID группы руками вписывать не нужно — бот сам её регистрирует.
7. При первом запуске с чистой папкой `storage/` все настройки создаются заново.

## Конфигурация (`configuration/conf.env`)

| Переменная | Назначение |
|---|---|
| `TOKEN` | токен бота от @BotFather |
| `OWNER_ID` | Telegram ID владельца (роль передаётся только через /admin) |
| `MANAGER_CHAT_ID` | стартовый чат заявок; после запуска меняется через /admin и хранится в `storage/settings.json` |

## Роли

- **Владелец** — назначает/удаляет админов, видит чаты бота, меняет чат заявок, может передать права.
- **Админ** — панель /admin, список админов, досье пользователей.

## Данные

- `storage/settings.json` — владелец, админы, чат заявок, известные чаты.
- `storage/answerbot.db` — SQLite: пользователи и история заявок (досье в /admin).
- `storage/fsm_state.json` — незавершённые опросы, восстанавливаются после рестарта.
